## 🎓 Course Overview

CS50AI covers the foundations of Artificial Intelligence and how to apply them using Python.

Key domains include:

- **Search algorithms** (BFS, DFS, A*, Greedy)
- **Knowledge representation** and logical inference
- **Constraint satisfaction problems (CSP)**
- **Uncertainty & probability**
- **Machine learning**
- **Neural networks**
- **Natural language processing (NLP)**
- **Reinforcement learning**
